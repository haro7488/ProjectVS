# 진행상황 확인

프로젝트 진행 상황을 확인하고 요약합니다.

## 사용법

```
/progress
```

## 실행 절차

1. **PROGRESS.md 읽기**
   - `Docs/PROGRESS.md` 파일을 읽습니다.

2. **요약 출력**

다음 형식으로 진행상황을 요약합니다:

```markdown
## ProjectVS 진행 상황

### 현재 단계: {단계명} {상태}

**마일스톤 현황**
| 단계 | 목표 | 상태 |
|------|------|------|
| M0 | ... | ... |
| ... | ... | ... |

**최근 완료**
- {최근 완료된 항목 3-5개}

**다음 작업**
- {예정된 작업 목록}

**최근 변경** ({날짜})
- {가장 최근 변경 내역}
```
