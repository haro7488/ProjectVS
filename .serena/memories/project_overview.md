# ProjectVS - Unity 프로젝트 개요

## 프로젝트 목적
- Unity 기반 게임/애플리케이션 프로젝트 (초기 단계)
- 프로젝트명: ProjectVS

## 기술 스택
- **엔진**: Unity (URP - Universal Render Pipeline 14.0.12)
- **언어**: C#
- **IDE 지원**: Visual Studio, Rider, VS Code
- **렌더링**: URP (Balanced, HighFidelity, Performant 프리셋)

## 주요 패키지
- TextMeshPro 3.0.7
- Timeline 1.7.7
- Visual Scripting 1.9.4
- Test Framework 1.1.33

## 프로젝트 구조
```
Assets/
├── Scenes/          # Unity 씬 파일
├── Scripts/         # C# 스크립트
├── Settings/        # URP 렌더링 설정
└── TutorialInfo/    # Unity 튜토리얼 에셋
```
