# 권장 명령어

## Windows 시스템 명령어
- `dir` - 디렉토리 목록 (ls 대신)
- `type` - 파일 내용 출력 (cat 대신)
- `findstr` - 텍스트 검색 (grep 대신)
- `cd` - 디렉토리 이동
- `copy`, `move`, `del` - 파일 조작

## Git 명령어
- `git status` - 현재 상태 확인
- `git add .` - 변경사항 스테이징
- `git commit -m "메시지"` - 커밋
- `git push` - 원격 푸시

## Unity 관련
- Unity Editor에서 직접 빌드/테스트 실행
- 테스트: Unity Test Runner 사용 (Window > General > Test Runner)

## .NET/C# 빌드
- `dotnet build` - 프로젝트 빌드 (Unity 외부)
- Unity 프로젝트는 Unity Editor를 통해 빌드
