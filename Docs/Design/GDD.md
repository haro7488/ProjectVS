# ProjectVS - Game Design Document

## 1. 개요

### 컨셉
> **현대 도시를 배경으로 한 뱀서라이크 서바이벌 게임**

끊임없이 몰려오는 적들을 자동 공격으로 처치하며 생존하는 로그라이트 액션 게임.

### 핵심 재미
- **성장의 쾌감**: 레벨업마다 강해지는 느낌
- **빌드 다양성**: 무기/아이템 조합의 재미
- **긴장감**: 점점 강해지는 적과의 줄다리기
- **달성감**: 클리어 및 언락 보상

### 레퍼런스
- Vampire Survivors (핵심 메카닉)
- Brotato (무기 시스템)
- 20 Minutes Till Dawn (전투 템포)

## 2. 핵심 루프

```
[메인 메뉴] → [캐릭터 선택] → [스테이지 진입]
                                    ↓
            [게임 오버] ← [전투] → [레벨업 선택]
                ↓                      ↓
         [보상 획득] ←──────────── [클리어]
                ↓
         [영구 성장] → [메인 메뉴]
```

### 세션 구조
| 구간 | 시간 | 내용 |
|------|------|------|
| 초반 | 0~5분 | 기본 무기로 적응, 첫 레벨업 |
| 중반 | 5~15분 | 빌드 완성, 무기 진화 |
| 후반 | 15~30분 | 보스 출현, 최종 생존 |

### 세션 길이
- **목표**: 15~20분 (일반 클리어)
- **최대**: 30분 (타임 리미트)

---

## 3. 전투 시스템

### 3.1 기본 규칙
- **자동 공격**: 무기가 자동으로 발사/휘두름
- **이동만 조작**: 플레이어는 이동만 담당
- **접촉 대미지**: 적과 접촉 시 피해

### 3.2 조작
| 플랫폼 | 이동 | 기타 |
|--------|------|------|
| PC | WASD / 방향키 | ESC: 일시정지 |
| 모바일 | 가상 조이스틱 | 화면 터치: 일시정지 |

### 3.3 적 스폰 규칙
- **웨이브 기반**: 시간에 따라 적 종류/수량 증가
- **방향**: 화면 밖 랜덤 방향에서 스폰
- **밀도 제한**: 동시 최대 적 수 제한 (성능)

### 3.4 대미지 계산
```
최종 대미지 = 기본 공격력 × (1 + 공격력%) × 크리티컬 배율
```

## 4. 성장 시스템

### 4.1 인게임 성장 (런 내)

#### 경험치 & 레벨업
- 적 처치 시 경험치 젬 드롭
- 젬 수집으로 경험치 획득
- 레벨업 시 3개 선택지 중 1개 선택

#### 레벨업 선택지
| 타입 | 내용 |
|------|------|
| 새 무기 | 무기 슬롯에 추가 (최대 6개) |
| 무기 강화 | 기존 무기 레벨업 (최대 Lv.8) |
| 새 패시브 | 패시브 슬롯에 추가 (최대 6개) |
| 패시브 강화 | 기존 패시브 레벨업 (최대 Lv.5) |

#### 무기 진화
- 조건: 무기 Lv.8 + 대응 패시브 보유
- 진화 시 강력한 상위 무기로 변환

### 4.2 영구 성장 (메타)

#### 골드 시스템
- 런 중 골드 획득 (적 드롭, 상자)
- 게임 오버/클리어 시 골드 유지

#### 영구 업그레이드
| 스탯 | 최대 레벨 | 효과 |
|------|-----------|------|
| 최대 체력 | 10 | +10% per level |
| 이동 속도 | 5 | +5% per level |
| 공격력 | 10 | +5% per level |
| 경험치 획득 | 5 | +10% per level |
| 골드 획득 | 5 | +10% per level |

## 5. 무기 & 아이템

### 5.1 기본 무기 (6개)

| 무기 | 타입 | 설명 | 진화 |
|------|------|------|------|
| 권총 | 투사체 | 가장 가까운 적에게 발사 | 기관총 |
| 나이프 | 투사체 | 이동 방향으로 발사 | 천 개의 칼날 |
| 야구 방망이 | 근접 | 전방 휘두르기 | 홈런 배트 |
| 화염병 | 범위 | 지면에 화염 지대 생성 | 지옥불 |
| 드론 | 궤도 | 플레이어 주변 회전 | 킬러 드론 |
| 번개 | 마법 | 랜덤 적에게 낙뢰 | 천둥 폭풍 |

### 5.2 패시브 아이템 (6개)

| 아이템 | 효과 | 진화 대응 |
|--------|------|-----------|
| 탄창 | 투사체 +1 | 권총 → 기관총 |
| 가죽 장갑 | 공격 속도 +10% | 나이프 → 천 개의 칼날 |
| 강화 그립 | 근접 범위 +15% | 야구 방망이 → 홈런 배트 |
| 기름통 | 지속 대미지 +20% | 화염병 → 지옥불 |
| 배터리 | 궤도 속도 +15% | 드론 → 킬러 드론 |
| 피뢰침 | 연쇄 횟수 +1 | 번개 → 천둥 폭풍 |

### 5.3 진화 조합표

| 무기 (Lv.8) | + 패시브 | = 진화 무기 |
|-------------|----------|-------------|
| 권총 | 탄창 | 기관총 |
| 나이프 | 가죽 장갑 | 천 개의 칼날 |
| 야구 방망이 | 강화 그립 | 홈런 배트 |
| 화염병 | 기름통 | 지옥불 |
| 드론 | 배터리 | 킬러 드론 |
| 번개 | 피뢰침 | 천둥 폭풍 |

## 6. 캐릭터

### 6.1 시작 캐릭터

#### 생존자 (Survivor)
- **시작 무기**: 권총
- **고유 스탯**: 없음 (기본)
- **언락 조건**: 기본 제공

### 6.2 언락 캐릭터

#### 러너 (Runner)
- **시작 무기**: 나이프
- **고유 스탯**: 이동 속도 +20%, 체력 -20%
- **언락 조건**: 10분 생존

#### 탱커 (Tanker)
- **시작 무기**: 야구 방망이
- **고유 스탯**: 체력 +50%, 이동 속도 -15%
- **언락 조건**: 첫 클리어

#### 파이로 (Pyro)
- **시작 무기**: 화염병
- **고유 스탯**: 범위 대미지 +30%
- **언락 조건**: 화염병 진화 달성

## 7. 스테이지

### 7.1 도시 외곽 (City Outskirts)
- **환경**: 황폐한 도시 외곽, 도로/폐건물
- **제한 시간**: 20분
- **클리어 조건**: 제한 시간 생존

#### 적 구성
| 시간 | 출현 적 |
|------|---------|
| 0~3분 | 좀비 (기본) |
| 3~7분 | 좀비 + 뛰는 좀비 |
| 7~12분 | + 대형 좀비 |
| 12~17분 | + 갱단원 |
| 17~20분 | 보스 + 모든 종류 |

#### 보스: 변이체
- **출현**: 17분
- **패턴**: 돌진, 범위 공격, 소환

### 7.2 지하철역 (Subway) - 추후 추가 예정
- **환경**: 어두운 지하철, 좁은 통로
- **특징**: 이동 제한, 높은 밀도

## 8. UI/UX

### 8.1 HUD 구성
```
┌─────────────────────────────────────┐
│ [HP Bar]              [시간] [골드] │
│                                     │
│                                     │
│           [게임 화면]               │
│                                     │
│                                     │
│ [무기 슬롯 1~6]  [패시브 슬롯 1~6]  │
│ [레벨/경험치 바]                    │
└─────────────────────────────────────┘
```

### 8.2 메뉴 흐름
```
[타이틀] → [메인 메뉴]
              ├── [게임 시작] → [캐릭터 선택] → [스테이지 선택] → [게임]
              ├── [영구 업그레이드]
              ├── [도감] (무기/적/캐릭터)
              └── [설정]
```

### 8.3 모바일 조작
- **가상 조이스틱**: 화면 좌측 하단 (드래그 생성)
- **일시정지**: 화면 우측 상단 버튼
- **레벨업 선택**: 화면 중앙 3개 버튼

## 9. 밸런스 기준

### 9.1 난이도 곡선
| 구간 | 체감 난이도 | 목표 |
|------|-------------|------|
| 0~5분 | 쉬움 | 적응, 첫 무기 강화 |
| 5~10분 | 보통 | 빌드 구축 |
| 10~15분 | 어려움 | 첫 진화, 긴장감 |
| 15~20분 | 매우 어려움 | 보스전, 클리어 |

### 9.2 예상 플레이 수치
| 항목 | 수치 |
|------|------|
| 첫 클리어 | 3~5회 시도 |
| 전체 언락 | 10~15시간 |
| 영구 성장 완료 | 20~30시간 |

### 9.3 수치 기준
| 항목 | 초기값 | 최종값 (풀빌드) |
|------|--------|-----------------|
| 플레이어 HP | 100 | 300+ |
| 이동 속도 | 5 | 7+ |
| 적 DPS (1분) | 5 | 50 |
| 플레이어 DPS | 10 | 500+ |
